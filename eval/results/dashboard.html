Indirect prompt injection · SOC / EDR telemetry narration

Can attacker-written telemetry talk the narrator out of reporting it?

Every payload below is spliced into a field an attacker on a monitored host controls directly — a process name, a command line, a file path, a DNS query, a registry key, a user agent — and fed to an LLM asked to summarise the incident. A bypass means the attack achieved its goal: the summary downgraded the severity, omitted the malicious entity, or was overridden outright. Select any row to see the raw payload and what each tier did with it.

Defense tiers

lower bypass rate is better
TIER 1 Naive
--bypass rate

Raw telemetry concatenated straight into the prompt. No delimiting, no typing, no framing.

TIER 2 Prompt-hardened
--bypass rate

Typed and escaped field tags, an explicit data-not-instructions system prompt, JSON-only output.

TIER 3 Structurally grounded
--bypass rate

Model picks one label per event from a fixed allow-list. Severity and entity text come from trusted code.
